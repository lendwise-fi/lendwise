## Decision and release ownership

Maintainers approve schemas/ADRs and backwards compatibility. Data/financial reviewers approve metric semantics, fees, corporate actions and comparison examples. Security/operations approve signing boundaries, source change response, migration/rollback and alerting. Product/partner owners confirm eligible journeys and provider agreements. A single successful API request cannot substitute for these approvals.
